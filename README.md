# ANIKKS Treats & Trend

A responsive storefront prototype for ANIKKS Treats & Trend, built with React and Vite.

## Brand
- Deep olive: `#24310B`
- Vibrant orange: `#FF8500`
- Cream: `#FFFCEF`
- Accent red: `#E5092B`
- Locations: Ifo and Ilaro, Ogun State, Nigeria
- WhatsApp: +234 916 225 9886
- Phone: +234 812 470 5254

## Included in this prototype
- Responsive homepage and mobile navigation
- Food, shades and perfume product catalogue
- Category filters and product search
- Interactive shopping bag with quantity controls
- WhatsApp order hand-off
- Moniepoint and business support service section
- About and contact sections

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

This is a front-end prototype. Product pricing and availability are sample catalogue data; WhatsApp checkout confirms the order with the business. Admin authentication, persistent product/order database, payment processing and production integrations are not yet connected.
